# Somali International University (SIU) Website

Full-stack university website starter using React + Vite, Express + Node.js, and MongoDB + Mongoose.

## Structure
- `client/` React frontend
- `server/` Express REST API

## Run

### Backend
```bash
cd server
npm install
cp .env.example .env
npm run dev
```

### Frontend
```bash
cd client
npm install
npm run dev
```

Frontend: http://localhost:5173
API: http://localhost:5000/api
